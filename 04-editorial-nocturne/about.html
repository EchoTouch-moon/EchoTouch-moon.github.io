Production notes

This review contains no JavaScript whatsoever. The grain is an inline SVG filter; the sidenotes are floats; the drop cap is a first letter. It renders identically in fifty years — assuming browsers still agree on floats, a wager I like.

fonts   : Newsreader (display) + Spectral (text) + JetBrains Mono (labels)
palette : cream #f7f3e9 · ink #201c15 · oxblood #7e2a2a · gold #a98d52
stack   : html + css. that's the whole build pipeline.
