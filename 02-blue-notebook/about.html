About this notebook

I keep this page the way one keeps a lab notebook: dated, cross-referenced, and honest about what failed.

What lives here

Long-form notes on systems programming, typography, and small tools. Short discoveries go straight into dated entries; anything that survives three rereads gets promoted to an essay.

Colophon

  • Type: Lora for body, Merriweather for titles, Ubuntu Mono for code — self-host or inline via Google Fonts.
  • The tide: the header and footer bands run lucumr.pocoo.org's WebGL water shader directly (by Armin Ronacher, source) — a crisp, full-bleed metaball sea. Hover a band and red accents surface one by one over ~2.65 seconds, then sink back. The footer is a 450px ocean, exactly like the original; only the page-blend and accent colors were adapted to this site's palette.
  • CSS trick: every color is written once with light-dark(); flipping color-scheme themes the whole site, and all colors cross-fade over 300 ms (suppressed on first paint, the lucumr way).
  • Little souls: page-to-page cross-fades via the View Transitions API, hover-reveal heading anchors, footnote pairing, code copy buttons, ink-thickening underlines, gap-sliding entry rows, a footer clock, and speculative prefetch. All vanilla, all respectful of reduced-motion.
  • Inspiration: lucumr.pocoo.org, manuelmoreale.com, paco.me, joshwcomeau.com, and the wider hand-made-web tradition.
