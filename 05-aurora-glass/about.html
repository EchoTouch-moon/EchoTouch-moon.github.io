# colophon

About.

I make small, glowing things for the web and write down how they work before the details fade. This site is both notebook and showcase.

The build

  • Weather: three drifting gradient blobs in pure CSS, frozen automatically under reduced-motion preferences.
  • Cards: backdrop-blur glass panels; hover lift is a transform, never a layout reflow.
  • Reading progress: one fixed div, one gradient, one scroll listener that stays passive.
  • Reveals: IntersectionObserver adds a single .in class; cascade delays live in CSS variables.
  • Type: Sora for display, Instrument Sans for body, Space Mono for timestamps and code.

Hosting it

Drop the folder on GitHub Pages / Netlify / Cloudflare Pages — or serve it from anything with an HTTP daemon. There is no build step: edit HTML, refresh, publish.
