Aurora in Ninety Lines of CSS.

The sky above this page is not a video, not a canvas, and not a single image. It is three radial gradients on loan from a sunset, drifting on independent clocks until they almost — but never quite — repeat.

The recipe

Each "blob" is a fixed-position pseudo-element with an enormous blur radius and its own animation duration. Desynchronizing the durations (26s / 32s / 38s) is what keeps the composition alive: the full pattern cycles only at their least common multiple, which is to say never within a sitting.

/* one blob, essence of */
.aurora::before {
  width: 46vw; height: 46vw;
  background: radial-gradient(circle,
    rgba(94, 234, 212, .5), transparent 65%);
  filter: blur(90px);
  animation: drift-a 26s ease-in-out infinite alternate;
}
@keyframes drift-a {
  to { transform: translate(14vw, 10vh) scale(1.15); }
}

Atmosphere should be noticed once, then forgotten — like good room temperature. If users mention your background in every message, it has become a roommate.

Costs & courtesies

Blur is the expensive part: filter: blur(90px) runs per frame while animating. Two mitigations ship with this template:

  • Blobs animate transform only — compositable, GPU-friendly.
  • @media (prefers-reduced-motion: reduce) freezes every drift without losing the color field itself.

Steal this

Open assets/style.css, find the aurora section, paste it into any dark theme. Change the three rgba stops and you have a new latitude. The glass cards are separately portable — backdrop-filter: blur(18px) saturate(150%) does most of the talking.
