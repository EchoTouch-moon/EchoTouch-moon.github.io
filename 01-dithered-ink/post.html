The Archive That Dreams

There is a particular magic in pictures made of two colors. One bit per pixel forces the machine to invent texture where reality only offered light — and the oldest trick it knows is to borrow order from a small square matrix.

Thresholds everywhere

Every display is a liar with limits: it cannot show gray between black and white unless it spends levels of brightness. Ordered dithering spends space instead, letting an 8×8 checkerboard of thresholds trade resolution for tone.1 The eye does the rest, averaging the noise into gradients that were never rendered.

def dither(image):
    # an 8x8 Bayer matrix turns tone into position
    bayer = [[(x ^ y) & 7 for x in range(8)] for y in range(8)]
    out = image.copy()
    for y in range(image.height):
        for x in range(image.width):
            level = image[x, y] / 255.0
            threshold = (bayer[y % 8][x % 8] + 0.5) / 64.0
            out[x, y] = "ink" if level > threshold else "paper"
    return out

The banner above this page runs the same idea live2: rain falls onto a quiet water surface while an ordered matrix decides which ink dots survive.

Why static pages suit this

  • No framework means the source is the archive — readable in fifty years by anyone with a browser.
  • CSS custom properties carry the whole mood; theming is one attribute flip.
  • A single <canvas> is enough atmosphere. Anything more is decoration for its own sake.
