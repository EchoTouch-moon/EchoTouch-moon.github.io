About

V.

Hello — I write essays about software craft, quiet interfaces, and the long memory of the web. By day I build systems; by night I take them apart to see what they were trying to say.

Colophon

  • Type: Fraunces for headlines, EB Garamond for body, IBM Plex Mono for code and dates.
  • Banner: an original WebGL fragment shader with pluggable scenes — rain on a pond (graded drizzle→storm), drifting clouds, and a weeping willow in the wind. Pick one with ?scene=rain|clouds|willow|dunes and grade the rain with &rain=drizzle|light|heavy|storm, or point the canvas at your own data-src video/photo to dither it the same way.
  • Machinery: hand-written HTML/CSS/JS. No framework, no build step, no tracking. Each page is a single file you can read from top to bottom.
  • Hosting: any static host works — GitHub Pages, Cloudflare Pages, or a folder on a Raspberry Pi under your desk.

Write here

To publish a post: duplicate post-template.html, give it a descriptive file name, replace the article content, then add its entry to index.html and archive.html. The repository README contains the complete checklist.
