## 1. 冒泡排序：两层循环进行排序

内外循环。每一轮比较相邻的两个元素，如果顺序相反就交换它们，每一趟走完都会将当前未排序部分的最大值「浮」到最后。

---

## 2. 插入排序：抽出比较

从第一个元素开始，把最前面的数组看作有序数组，再一个一个把后面的数插入到它应有的位置上去。

---

## 3. 希尔排序：先分组，再进行插入排序

- **分组规则**：一般初始分组步长为数组长度的一半；每次分组之后都要进行插入排序。
- 每完成一轮排序后，步长折半，直到步长间隔减为 1 进行最后一次直接插入排序。

---

## 4. 快速排序

### 方法一：指针交换法（双边）

1. 先将数组的第一个元素作为基准值（`base`）；
2. 先移动右指针，从右往左找，直到找到比基准值小的数停止（右找小）；
3. 再移动左指针，从左往右找，直到找到比基准值大的数字停止（左找大）；
4. 交换左右指针处的值；
5. `while` 循环继续上述操作，直到左右指针重叠；
6. 将指针重叠处的值与基准值交换；
7. 交换完成后，数组就被分为了以基准值为界的两部分（左侧比基准值小，右侧比基准值大）；
8. 分别对左右两部分的子数组递归调用本函数（注意更新子数组的起始与结束索引）；
9. **递归结束条件**：`i >= j`。

```c
void quick_sort0(int* arr, int start, int end) {
    int i, j, base;
    i = start;
    j = end;
    base = arr[start];  // 这一个值即为基准点
    if (i >= j) {
        return;  // 结束条件，看两个指针的位置
    }

    while (i != j) {
        while (arr[j] >= base && i < j) {
            j--;   // 右指针左移
        }
        while (arr[i] <= base && i < j) {
            i++;   // 左指针右移
        }
        if (i < j) {   // 如果左指针小于右指针，交换两个位置的数
            swap(&arr[i], &arr[j]);
        }
    }

    swap(&arr[start], &arr[i]);   // 把基准值与指针重叠的数交换位置，完成左右划分
    // 这里表示排列左边的数(通过更改起始与结束的值)，递归直到排序完成
    quick_sort0(arr, start, i - 1);
    // 这里表示排列右边的数(通过更改起始与结束的值)
    quick_sort0(arr, i + 1, end);
}
```

### 方法二：挖坑法（单边）

1. 先将数组的第一个元素取出作为基准值（此时首位置形成第一个“坑”）；
2. 移动右指针寻找比基准值小的数，将找到的数填入左指针位置的坑中（此时右指针位置成了新坑）；
3. 移动左指针寻找比基准值大的数，将找到的数填入右指针位置的坑中（此时左指针位置再次成坑）；
4. 重复以上过程直到左右指针相遇；
5. 将基准值填入最后相遇处的坑中，完成一趟分组划分；
6. 分别对划分好的左右子数列递归执行相同的操作。

```c
void quick_sort1(int* arr, int start, int end) {
    int i, j, base;
    i = start;
    j = end;
    base = arr[start];

    if (i >= j) {  // 结束条件
        return;
    }

    while (i != j) {   // 右指针左移，直到找到比基准值小的数
        while (arr[j] >= base && i < j) {
            j--;
        }
        if (i < j) {    // 将右指针处的值填入左指针的坑中
            arr[i] = arr[j];
        }
        while (arr[i] <= base && i < j) {   // 左指针右移直到找到比基准值大的数字
            i++;
        }
        if (i < j) {   // 将左指针处的值填入右指针的坑中
            arr[j] = arr[i];
        }
    }
    // 将基准值填入最后空出的坑中
    arr[i] = base;
    // 递归调用排序左右子数组
    quick_sort1(arr, start, i - 1);
    quick_sort1(arr, i + 1, end);
}
```

### 辅助函数：指针交换两个数的值

```c
void swap(int* a, int* b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}
```
